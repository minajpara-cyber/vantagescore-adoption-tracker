How this is measured

  • The model that priced a loan comes from the Pricing Indicator the GSEs began disclosing in October. Before that, each loan disclosed only the score it was priced with, so the populated score field identifies the model.
  • Shares count loans with a valid credit score. Pools that disclose no score, mostly re-performing loans, are left out.
  • Issue month comes from the GSEs' month-end issuance files, the official list for each month. The latest month uses intraday files and will change until its month-end file is published.
  • The weekly series dates each loan by its first appearance in an intraday file. Loans are republished for up to a few weeks, so the series starts three weeks after the portal's intraday history begins.
  • Source: Fannie Mae PoolTalk and Freddie Mac MBS disclosure loan-level issuance files, intraday and month-end, through —. Only these aggregates are published here; loan-level data stays on the computer that built them.
